# AquaSense AI

A responsive water-quality and disturbance analysis dashboard.

## Features
- Seven water-quality inputs
- Transparent quality scoring
- Disturbance detection
- Risk assessment and recommendations
- Local analysis history
- CSV export
- Demo values
- Dark/light theme
- Responsive design
- GitHub Pages ready

## Run
Open `index.html` in a browser.

## Note
This portfolio project uses simplified reference ranges and a transparent client-side scoring engine. It is not a substitute for certified laboratory testing or local regulatory standards.
